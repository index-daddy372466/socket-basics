## Chat with Animals (chat rooms)

That is right.
Chat with real people, a.k.a. animals, on the world wide web about absolutely anything!
Chatrooms can be created by anyone (optional) & utilized for real-time communication.

### Features: 

1. Start a user session by creating a **dispaly-name**
2. Each session is hashed.
3. Each session is limited.
4. Represent your character with a wild animal.
5. Animal much be chosen to enter a room.
6. Create & join a chatroom.


### Languages & frameworks:

1. HTML
2. CSS
3. Javascript
4. NodeJS
5. Socket.io
